# 오늘은 어떤 빵을 먹을까?

- 서비스 링크: [GitHub Pages](https://seoheejung.github.io/bread-today/)
- 추가 링크: [Link24](https://link24.kr/H6kiXFB)

> 12개의 선택을 통한 오늘의 베이커리 취향 테스트

## 소개

- 맛·식감·풍미·먹는 방식에 대한 선택 기반 빵 추천 서비스
- 실제 베이커리 취향을 기준으로 한 4개 축 판정
- 12개 질문의 응답 조합에 따른 16가지 결과 중 하나 추천

- 취향 코드와 결과 데이터의 1:1 매칭

## 판정 방식

- 취향 축별 3문항 구성
- 식사 후·커피 한 모금·영화 감상·친구와 나눠 먹기 등의 상황 중심 질문
- 축 이름·재료 목록의 직접 나열을 줄인 경험 중심 선택지
- 성격·생활 계획의 판정 대상 제외
- 축별 다수 선택값을 최종 성향으로 사용

```text
맛
D D S
→ D

식감
T T M
→ T

풍미
R L R
→ R

구성
B B F
→ B
```

최종 코드:

```text
DTRB
```

결과:

```text
퀸아망
```

- 축별 홀수 문항 구성에 따른 동점 방지
- 동일 응답에 대한 동일 결과 반환

| 실행 정책 | 해시 기반 CSP·미허용 스크립트·인라인 이벤트·네트워크 요청 차단 |

| HTTPS | 공개 GitHub Pages 주소의 HTTP → HTTPS 리다이렉트 및 HSTS 응답 확인 |
| 종속성 | 외부 런타임 라이브러리·패키지 매니페스트·설치 의존성 없음 |

- 서버·API·DB·로그인·세션·비밀번호·사용자 콘텐츠·파일 업로드 기능 미사용
- DB 키·행 수준 보안·암호화 저장·서버 인증·레코드 권한·필드 변조·쿠키·비밀번호 해싱·로그인 제한·봇 보호·SQL 매개변수화·업로드 제한·API 응답 정리의 적용 대상 없음
- `frame-ancestors`·`X-Content-Type-Options` 등 HTTP 응답 헤더의 추가 적용에는 호스팅 설정 필요
- HTML 메타 CSP에서 `frame-ancestors` 지원 없음·호스팅 헤더 적용 여부와 HTML 정책의 구분
- 보안 정책 참고: [MDN CSP](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy), [MDN frame-ancestors](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-ancestors)
- 호스팅 참고: [GitHub Pages HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https), [GitHub Pages 맞춤 404](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-custom-404-page-for-your-github-pages-site)
